# LCR Skill — Leader and Clerk Resources Navigation

## Purpose

Help users navigate LCR (Leader and Clerk Resources) to complete common administrative tasks. LCR is the Church's primary tool for managing membership records, callings, ministering, reports, and finances.

## Access

**URL:** https://lcr.churchofjesuschrist.org

**Who has access:**
- Bishopric members
- Ward clerk and assistant clerks
- Executive secretary
- EQ and RS presidents (limited)
- Stake presidency and clerks
- Other leaders with specific permissions

**Access levels vary by calling** — some features only visible to clerks or bishopric.

## LCR Main Sections

| Section | Who Uses It | Key Functions |
|---------|-------------|---------------|
| **Member Directory** | All leaders | View member info, contact details |
| **Ministering** | EQ/RS presidents, bishopric | Assignments, interviews, tracking |
| **Callings** | Bishopric, clerk | Current callings, sustaining, releases |
| **Membership** | Clerk, bishopric | Records, move-ins/outs, ordinances |
| **Reports** | Clerk, bishopric | Quarterly report, action items, statistics |
| **Finance** | Clerk, bishopric | Donations, budgets, expenses |
| **Temple Recommends** | Bishopric, stake presidency | Track status, renewals, expiring |
| **Organizations** | All leaders | Class lists, attendance |

## Navigation Tips

### Finding Things
- **Search bar** (top) — search members by name
- **Left sidebar** — main navigation sections
- **Hamburger menu** (mobile) — collapsed navigation

### Common Gotchas
- Some actions require **clerk** role (bishopric sees but can't edit)
- **Move-ins** appear in a separate queue — check regularly
- **Ministering** updates may take time to sync
- **Reports have deadlines** — quarterly reports due by specific dates

## Troubleshooting

**Can't see a feature?**
- Check if your calling has access
- Try refreshing or logging out/in
- Contact stake clerk if permissions seem wrong

**Data not updating?**
- LCR syncs periodically, not instantly
- Major changes (moves) can take 24-48 hours
- If stuck, contact Church support

**Mobile vs Desktop**
- Some features work better on desktop
- Reports and complex edits — use desktop
- Quick lookups — mobile is fine
