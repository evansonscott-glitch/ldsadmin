# LCR Callings Management

## Overview

LCR tracks all callings in the ward — who holds them, when they were sustained, and organizational structure.

## Access

**Path:** LCR → Callings (or Organizations)

**Who can access:**
- Bishopric — Full access
- Ward Clerk — Full access
- Executive Secretary — View access
- Organization presidents — Their organization only

---

## Viewing Current Callings

### By Organization
**Path:** LCR → Organizations → [Select Organization]

Shows:
- All positions in that organization
- Who currently holds each calling
- Sustaining date
- Vacant positions

### By Member
**Path:** LCR → Membership → [Search Member]

Each member's record shows:
- Current calling(s)
- Past callings
- Sustaining and release dates

### All Callings Report
**Path:** LCR → Reports → Callings

Full ward calling list, printable for:
- Ward council
- Stake reports
- Planning purposes

---

## Calling Someone to Serve

### Workflow
1. **Prayerful consideration** — Bishopric discusses and decides
2. **Worthiness interview** — If required for the calling
3. **Extend the calling** — Bishopric member meets with member
4. **Record in LCR** — Add pending calling
5. **Sustaining** — Present in sacrament meeting
6. **Setting apart** — Confer authority and blessing
7. **Complete in LCR** — Mark as sustained/set apart

### Recording a New Calling
**Path:** LCR → Organizations → [Organization] → Add Calling

1. Navigate to the organization
2. Click the vacant position (or **Add**)
3. Search for and select the member
4. Enter proposed sustaining date
5. Save

### After Sustaining
1. Return to the calling in LCR
2. Mark as **Sustained**
3. Enter sustaining date
4. After setting apart, mark **Set Apart**
5. Enter set apart date

---

## Releasing Someone

### When to Release
- Called to another position
- Moving out of the ward
- Personal circumstances require it
- Calling no longer needed
- Natural end of service

### Recording a Release
**Path:** LCR → Organizations → [Find Calling] → Release

1. Find the person's current calling
2. Click **Release** (or edit the calling)
3. Enter release date
4. Save

### Best Practices
- Inform person privately before public release
- Express gratitude for service
- Present for vote of thanks in sacrament meeting
- Record release date in LCR

## Vacant Positions

### Finding Vacancies
**Path:** LCR → Reports → Vacancies

Lists all unfilled callings across the ward.

### Positions That Need Filling
Priority usually:
1. Bishopric (if vacancy)
2. Organization presidencies
3. Teachers
4. Support callings

### Positions That May Stay Vacant
- Some wards combine callings
- Small wards may not fill all positions
- Stake can advise on requirements

---

## Callings Requiring Approval

Some callings require stake approval before extending:

### Stake Approval Required
- Bishopric counselors
- Elders Quorum presidency
- Ward clerk
- Certain other callings (check with stake)

### Process
1. Bishopric recommends candidate
2. Submit to stake presidency
3. Wait for approval
4. Then extend calling

### How to Request Approval
- Contact stake executive secretary
- Or use stake's preferred process
- Some stakes use online forms

## Temple Recommend Required

Some callings require a current temple recommend:

- Bishopric
- Temple workers
- Seminary/Institute teachers
- Others as determined by handbook

### Checking Recommend Status
**Path:** LCR → Temple → [Member Name]

Or check in member's individual record.

## Tips

1. **Keep LCR updated** — Record callings promptly after sustaining
2. **Don't record before sustaining** — Wait until public sustaining
3. **Use correct dates** — Sustaining date = the Sunday they were sustained
4. **Check vacancies regularly** — Don't let critical callings sit empty
5. **Coordinate with clerk** — Clerk often handles the LCR entries
