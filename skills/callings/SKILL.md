# Callings Skill — Calling-Specific Playbooks

## Purpose

Provide practical guidance for members serving in specific callings. Each playbook covers responsibilities, typical workflows, common challenges, and tips for success.

## Available Playbooks

| Calling | File | Key Focus |
|---------|------|-----------|
| Bishop | `bishop.md` | Presiding, welfare, youth interviews, councils |
| EQ President | `eq-president.md` | Ministering, welfare, service, quorum strengthening |
| RS President | `rs-president.md` | Ministering, welfare, sisterhood, coordination |
| Ward Clerk | `ward-clerk.md` | Records, finances, reports, LCR |
| Executive Secretary | `exec-secretary.md` | Scheduling, communication, bishopric support |
| Primary President | `primary-president.md` | Children's programs, teachers, sacrament presentations |
| YW President | `yw-president.md` | Youth development, activities, Personal Development |
| Sunday School President | `sunday-school-president.md` | Gospel teaching quality, teacher support |
| Ward Mission Leader | `ward-mission-leader.md` | Missionary coordination, member involvement, converts |

## How Sam Uses Playbooks

When a user's calling is identified:
1. Load the relevant playbook
2. Reference it when answering calling-specific questions
3. Proactively suggest relevant workflows
4. Tailor meeting and admin support to the calling

## Customization

These playbooks are starting points. Sam should:
- Learn the user's specific ward/stake practices
- Adapt to their bishop's and stake president's preferences
- Note what works and what doesn't for this user

## Adding New Playbooks

To add a calling not yet covered:
1. Create `[calling-name].md` in this folder
2. Include: Overview, Key Responsibilities, Typical Meetings, Common Workflows, Tips
3. Reference handbook sections where applicable
